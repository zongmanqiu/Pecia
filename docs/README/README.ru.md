# Pecia — минималистичный текстовый редактор

---

**[⬇️ Скачать последнюю версию (1.1.1) (Gitee)](https://gitee.com/qiuzongman/pecia/releases/download/1.1.1/Pecia_x64_1.1.1.zip)** ｜ **[⬇️ Скачать последнюю версию (1.1.1) (GitHub)](https://github.com/zongmanqiu/Pecia/releases/download/1.1.1/Pecia_x64_1.1.1.zip)** ｜ [Репозиторий Gitee](https://gitee.com/qiuzongman/pecia) ｜ [Зеркало GitHub](https://github.com/zongmanqiu/Pecia) | [Демо на Bilibili](https://www.bilibili.com/video/BV144Yo6oEz9/)

Легковесный текстовый редактор для Windows на базе C++17 + FLTK. Много вкладок, мгновенное открытие больших файлов, поддержка множества кодировок, расширение скриптами на Lua. Новое: боковая панель (дерево файлов/структура), диалог выбора шрифта, тени окон; предпросмотр Markdown рендерит очень большие документы по блокам.

> **Платформа**: поддерживается только **Windows x64 (64 бит)**. 32-битная версия не предоставляется, кроссплатформенная поддержка (Linux/macOS/32 бита) более не ведётся. Скрипты сборки включают проверку на 64-битность (см. начало CMakeLists); при ошибочной конфигурации 32 бит будет выдана ошибка.

## Быстрый старт

### Требования к среде (помимо исходного кода и сторонних библиотек)

- Windows 10/11 x64 (1803+; встроенные утилиты curl/tar)
- **Visual Studio Build Tools 2022 / VS2022** (с рабочей нагрузкой «Разработка на C++ для Windows»)
  - Скрипт `build/msvc_env.bat` **автоматически определяет** MSVC и Windows SDK (не зависит от vcvars/vswhere/командной строки разработчика; обычный cmd подойдёт). Также можно указать кастомные пути через переменные окружения `PECIA_MSVC_ROOT` / `PECIA_SDK_ROOT`.
- **CMake ≥ 3.16** (должен быть в PATH; генератор — **NMake Makefiles**, Ninja не нужен)
- **Цепочка инструментов Rust** (≥ 1.85, edition 2024; для компиляции FFI-библиотек mmdr и RaTeX; устанавливается через https://rustup.rs; первая сборка требует подключения к интернету для загрузки зависимостей из crates.io)
- **Подключение к интернету** (только при первой сборке: `2_download.bat` загружает зависимости, `4_build_rust.bat` выполняет `cargo fetch`)
- **git не требуется** (зависимости загружаются через curl и распаковываются tar)

### Сборка (рекомендуется: один двойной клик)

```bat
REM После скачивания исходного кода просто дважды щёлкните по этому скрипту.
REM Он последовательно выполняет: 1 проверка цепочки инструментов → 2 загрузка 6 сторонних библиотек → 3 применение патчей →
REM 4 cargo fetch + сборка двух Rust FFI → 5 сборка FLTK + CMake сборка Pecia →
REM запуск 26 unit-тестов.
REM Время первой сборки зависит от сети и мощности ПК; повторные сборки используют кэш, инкрементальная сборка + тесты занимают ~1-2 минуты.
build\full.bat
```

> Step-by-step build scripts, tests and packaging: see `build/build_readme.md`. Release process: see `docs/RELEASE_CHECKLIST.md`. Архитектурный дизайн (модель процессов/слои/подсистемы): см. «Обзор архитектуры» в начале `开发指南.md`.

## Структура каталогов

```
main/
├── CMakeLists.txt      Правила сборки (точка входа CMake)
├── main.cpp            Точка входа программы
├── README.md           Данная документация (описание проекта/загрузка/интерфейс/вход в сборку)
├── docs/               Версии README на других языках (README.<lang>.md) + скриншоты интерфейса + intro.pptx
├── 目录结构说明.md      Описание каталогов и модулей (обязательно к прочтению при работе над проектом)
├── 开发指南.md         Процесс разработки/релиза, обзор архитектуры и чек-лист перед коммитом
├── AGENTS.md           Инженерные соглашения (участники/правила ИИ)
├── HISTORY.md          История версий (при релизе добавлять новый раздел версии вверху; старое содержимое не изменять)
├── LICENSE             Дословный официальный текст AGPL-3.0 (UTF-8, без BOM; условия нельзя изменять)
├── THIRD-PARTY-NOTICES.md  Уведомления о сторонних библиотеках (название/версия/лицензия/число патчей)
├── .gitignore          Правила игнорирования системы контроля версий
├── .gitattributes      Правила окончаний строк и текстовых атрибутов
├── core/               Чистая бизнес-логика (без UI)
├── editor/             Виджет редактора
├── ui/                 Окна/диалоги/панели инструментов
├── LuaTool/            Отдельный инструмент PeciaLua (окно/точка входа/сервер именованных каналов)
├── AIChat/             Отдельный инструмент PeciaAIChat (окно/точка входа)
├── script/             Скриптовый движок Lua
├── DOCS_MANIFEST.md    Реестр документации (проверяется test_docs после изменений кода; только для разработки, не поставляется с exe)
├── image/              Ресурсы изображений (pecia.ico / ai_bot.ico / lua.ico …)
├── test/               Исходники unit-тестов
├── lang/               Файлы локализации (16 × .ini)
├── theme/              Файлы тем оформления (light.ini/dark.ini/cream.ini/mint.ini/ice.ini)
├── example/            Примеры документации (демонстрация рендеринга Markdown: диаграммы Mermaid, формулы LaTeX, изображения и т.д.)
├── patches/            Архив модификаций сторонних библиотек (применяются автоматически при сборке)
├── mdview/             Предпросмотр Markdown (панель предпросмотра/рендеринг HTML, включая FFI-заголовки mmdr)
└── build/              Скрипты сборки и вспомогательный исходный код
```

## Технологический стек

| Компонент | Версия | Репозиторий |
|---|---|---|
| C++ | C++17 | — |
| FLTK | 1.4.5 | https://github.com/fltk/fltk |
| Lua | 5.5.1 | https://github.com/lua/lua |
| PCRE2 | 10.47 | https://github.com/PCRE2Project/pcre2 |
| md4c | 2026-09-11 (10fa4f44) | https://github.com/mity/md4c |
| litehtml | 0.10 | https://github.com/litehtml/litehtml |
| stb | 2026-08-02 (2c980bb5) | https://github.com/nothings/stb |
| mmdr (mermaid-rs-renderer) | 0.3.1 | crates.io (cargo) |
| RaTeX (рендеринг формул, встроенный) | 0.1.14 | crates.io (cargo) |
| Rust | ≥ 1.85 | https://rustup.rs |
| Сборка | CMake + NMake Makefiles + MSVC | — |

> Подсказка: допускается локальное изменение сторонних библиотек; изменённые файлы необходимо
> сохранять в `main/patches/<имя_библиотеки>/` (при сборке 3_patch.bat автоматически перезаписывает).
> При обновлении версий необходимо заново применить патчи (см. пример в build/FLTK_PATCHES.md).
> mmdr включает resvg 0.47 (единственный растеризатор SVG в проекте: и диаграммы mermaid, и SVG формул LaTeX растеризуются в PNG именно им); RaTeX только генерирует SVG-строки и напрямую не зависит от resvg.
