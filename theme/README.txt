# Pecia 主题说明（theme/ 文件夹）

本目录存放配色主题文件。每个 `.ini` 文件 = 一套完整配色。settings.ini
只记录当前选中的主题名（theme.name = <文件名不带后缀>），颜色值都从
`theme\<主题名>.ini` 读取。

## 内置主题（light）
只有 light 是内置的，损坏后程序会自动重新生成。

| 文件名        | 风格               | 说明               |
| ---------     | ------------       | ----               |
| light.ini     | 亮色（默认）       | 浅色、白底          |

## 附带主题（dark/cream/mint/ice）
随编译提供，程序启动时自动扫描 theme/ 目录生成菜单。

| 文件名        | 风格               | 说明               |
| ---------     | ------------       | ----               |
| dark.ini      | 暗色               | 纯黑底 + 青强调     |
| cream.ini     | 暖色               | 奶油底 + 橙强调     |
| mint.ini      | 清新绿             | 薄荷底 + 金强调     |
| ice.ini       | 冰蓝               | 冰蓝底 + 紫强调     |

## 怎么用
1. 在程序里：「View(视图) → Theme(主题)」选择。
2. 手动：改 `theme/<名字>.ini` 里的某个颜色，重启或切到该主题即生效
   （运行中的程序改了文件不会热刷，需重启或重新切一次）。

## 新增主题
1. 复制 `light.ini` → 改名为 `theme/<我的主题>.ini`。
2. 编辑里面的颜色值（包括 name 和 name.zh-CN）。
3. 重启程序，新主题会自动出现在菜单中。

## 8 键颜色模型
全部 UI 元素映射到 8 个语义色，多种元素共用同一色，保持视觉和谐：
**text1 —— 主文字 + 所有边框线 + 标签关闭图案**
- 编辑区、标题栏、菜单栏、脚本栏、行号列、状态栏/find 栏、go to 栏文字
- 各类文本输入区域文字。AI chat 与 Lua 控制台文字
- 窗口边框、按钮边框、选项边框
- 标签关闭图标（非悬停状态）

**text2 —— 次要/提示/禁用文字（标签、副标题、占位符）**
- 副标题、快捷键提示、禁用项、占位符
- Find/GoTo 栏标签（"查找："、"行："）

**background1 —— 工作区背景（编辑器/输入框/对话框主体/滚动条轨道）**
- 编辑器背景、输入框背景、对话框主体
- 滚动条轨道

**background2 —— 框架背景（标题栏/状态栏/滚动条滑块）**
- 标题栏背景、状态栏背景
- 滚动条滑块

**background3 —— 过渡背景（菜单栏/行号/find/go-to栏/脚本栏）**
- 菜单栏背景、脚本栏背景
- Find/GoTo 栏背景
- 行号背景

**highlight1 —— 悬停/当前行/标签页激活/按钮选中**
- 菜单项悬停背景、标签页激活背景
- 当前行高亮背景、链接悬停背景
- 按钮选中状态（selection_color）

**highlight2 —— 文本选中/按钮按下/菜单勾选框填充**
- 文本选中背景、输入框选中背景
- 按钮按下状态（setPressColor）
- 菜单勾选框填充、复选框/单选框选中

**highlight3 —— 搜索命中/链接/关闭悬停/冲突警告**
- 搜索匹配高亮背景
- URL 悬停颜色
- 标签关闭按钮悬停背景
- 快捷键冲突警告颜色

## 主题文件格式（.ini）
```
# 键 = 值，值支持 #RRGGBB 或 R,G,B。缺省键使用内置默认值。
# 所有主题统一 8 键（见上节）：
name = Light            # 主题英文名（必填）
name.zh-CN = 亮色       # 中文名（可选，支持多语言）

text1        = #000000    # 主文字 + 所有边框线 + 标签关闭图案
text2        = #8C8C8C    # 次要/提示/禁用文字（标签、副标题、占位符）
background1  = #FFFFFF    # 工作区背景（编辑器/输入框/对话框主体/滚动条轨道）
background2  = #E1E1E1    # 框架背景（标题栏/状态栏/滚动条滑块）
background3  = #F0F0F0    # 过渡背景（菜单栏/行号/find/go-to 栏/脚本栏）
highlight1   = #E6FFE6    # 悬停/当前行/标签页激活/按钮选中
highlight2   = #96FFC8    # 文本选中/按钮按下/菜单勾选框填充
highlight3   = #FF6464    # 搜索命中/链接/关闭悬停/冲突警告
```
代码读取逻辑见 core/Theme.cpp（加载 theme/%s.ini）。
