# Pecia third-party dependency list
# Read by 2_download.bat: each active line is downloaded and
# extracted to .thirdparty/<name>/.
#
# Format: name=url
#         name=url|marker-file
# The extracted top-level dir is renamed to "name" automatically.
# The optional "marker-file" (a path RELATIVE to .thirdparty/<name>/) is the
# integrity probe: the library counts as "already present" only if that file
# exists. This guards against a half-extracted directory left behind by an
# interrupted download, which would otherwise be mistaken for a complete one.
#
# IMPORTANT: keep this file ASCII-only. cmd's "for /f" parses it in the OEM
# code page; non-ASCII bytes (e.g. CJK comments) get mangled and can swallow
# the following "name=url" lines, silently skipping dependencies.
# (Chinese notes for these libraries live in build_readme.md / README.md.)
#
# IMPORTANT: GitHub-hosted libraries use
#   https://codeload.github.com/<owner>/<repo>/tar.gz/<ref>
# instead of
#   https://github.com/<owner>/<repo>/archive/<ref>.tar.gz
# Both serve the same archive (codeload is GitHub's archive host and is what
# the archive/ URL redirects to). We link codeload directly because the
# github.com/archive and github.com/releases paths return HTTP 502 behind
# restrictive HTTP proxies, while codeload works through both direct and
# proxied connections. lua.org is not on GitHub and is used as-is.
#
# Set PECIA_FORCE_DOWNLOAD=1 to ignore the cache/presence checks and re-fetch
# every library from scratch (useful when .thirdparty/ is suspected corrupt).
